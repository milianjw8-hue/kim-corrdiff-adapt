# 방법 (Methods)

## 1. 입력 분포 차이 진단

KIM과 ERA5가 함께 있는 시각만 씁니다. 변수마다 모든 시각과 격자점을 모아 계산합니다.

| 지표 | 정의 | 뜻 |
|---|---|---|
| `mean_bias` | 평균(KIM) − 평균(ERA5) | 체계적 편차 |
| `std_ratio` | 표준편차(KIM) / 표준편차(ERA5) | 변동성 차이 |
| `w1` | 1-바서슈타인 거리. 분위수 199개(0.5~99.5 %)에서 \|q_KIM(p) − q_ERA5(p)\|의 평균 | 분포 전체의 차이 |
| `w1_norm` | `w1` / 표준편차(ERA5) | 단위 없는 값. 변수끼리 비교 가능 |
| `z_shift` | (평균(KIM) − 학습 평균) / 학습 표준편차 | 학습 정규화 기준에서 KIM이 얼마나 벗어났는지 |

`needs_correction`은 아래 중 하나를 넘으면 참입니다. **선별용 경험값**이며 문헌 근거는 없습니다.

- `w1_norm` > 0.10
- `std_ratio` < 0.90 또는 > 1.10
- \|`z_shift` − `z_ref`\| > 0.10 (`z_ref`: 같은 기간 ERA5의 값)

격자점별 시간 평균 차이와 표준편차 비 지도(`--maps`)로 지형·해안 같은 공간 구조도 확인합니다.

## 2. 분위수 사상

맞춤 기간의 KIM과 ERA5에서 확률 p = 0.01, 0.02, …, 0.99의 분위수 q_KIM(p), q_ERA5(p)를 구합니다.
새 KIM 값 x는 다음처럼 바꿉니다.

1. KIM 분위수에서 x의 확률 p를 선형 보간으로 찾습니다.
2. 더하기형: x' = x + (q_ERA5(p) − q_KIM(p))
   곱하기형(강수처럼 음수가 없는 변수): x' = x · q_ERA5(p) / q_KIM(p), 0 이상으로 자릅니다.
3. p가 0.01보다 작거나 0.99보다 크면 끝 값의 보정량을 그대로 씁니다.

선택 사항은 다음과 같습니다.

- 격자점별(`pointwise`) 또는 영역 전체(`--pooled`). 격자점별은 지역 편차까지 고치지만 자료가 많이 필요합니다.
- 계절별(`season`: DJF, MAM, JJA, SON), 월별(`month`), 또는 나누지 않음(`none`). 한 무리의 시각이 30개보다 적으면 오류를 냅니다.

**평가:** 맞춤에 쓰지 않은 해(`--test-years`)에서 사상 전후의 1절 지표를 비교합니다. 같은 해로 맞추고 평가하면 효과가 부풀려집니다.

**한계:** 변수 하나의 분포만 맞춥니다. 공간 상관, 변수 사이 관계(예: 바람 성분과 기압 경도), 시간 연속성은 보장하지 않습니다.
그래서 B 실험의 최종 판단은 다운스케일링 결과의 지점 검증으로 합니다.

## 3. 정규화 통계

PhysicsNeMo CorrDiff `hrrr_mini` 데이터셋은 다음 JSON을 읽습니다.

```json
{"input": {"u10m": {"mean": 2.0, "std": 5.0}, ...},
 "output": {...},
 "invariant": {...}}
```

입력 채널 x는 (x − mean) / std로 바뀝니다. 실험 C는 `input`만 KIM 학습 기간 값으로 바꾸고 `output`과 `invariant`는 그대로 둡니다.
출력 통계를 바꾸면 사전학습 모델의 출력 의미가 달라지므로 바꾸지 않습니다.

## 4. 자료 형식

`kcadapt export`는 PhysicsNeMo `datasets/hrrrmini.py`가 읽는 구조로 씁니다.

| 위치 | 내용 |
|---|---|
| `/time`, `/coord` | 시각, 표본별 불변장 시작 위치 (전체 영역이면 0, 0) |
| `/input/<변수>` | (time, y, x) 저해상도 입력 |
| `/output/<변수>` | (time, Y, X) 고해상도 정답, Y = f·y, X = f·x |
| `/invariant/<변수>` | (Y, X) 지형, 해륙 마스크 등 |

읽는 쪽이 입력을 f배로 쌍선형 확대하므로, 저해상도 격자는 고해상도 영역과 모서리가 맞아야 합니다.

## 5. 실험 설계

| 실험 | 바꾸는 것 | 확인하려는 질문 |
|---|---|---|
| R | 없음 (ERA5) | 사전학습 모델의 기준 성능 |
| A | 입력만 KIM으로 | 아무 적응 없이 쓰면 얼마나 나빠지나 |
| B | KIM 분위수 사상 | 입력 분포만 맞추면 충분한가 |
| C | 입력 정규화 통계를 KIM으로 | 평균·분산만 다시 맞추면 충분한가 |
| D | 회귀 UNet 추가 학습 (확산 고정) | 재학습이 필요한가, 얼마나 나아지나 |

CorrDiff는 회귀 UNet이 평균장을, 확산 모델이 잔차(작은 규모 변동)를 만듭니다(Mardani et al. 2025).
입력 분포 차이는 주로 평균장에 영향을 준다고 보고(추정), D에서는 회귀 UNet만 추가 학습합니다.
결과가 나쁘면 확산 모델까지 추가 학습하는 실험을 더합니다.

**공정 비교:** 모든 실험은 같은 평가 기간, 같은 지점, 같은 앙상블 수(`num_ensembles`)로 비교합니다.
D의 학습 기간과 평가 기간은 겹치지 않아야 합니다. B의 분위수 사상 맞춤 기간도 평가 기간과 겹치지 않아야 합니다.
